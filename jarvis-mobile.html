J.A.R.V.I.S.
OFFLINE
Tap ACTIVATE, then say "Hey Jarvis".
Works without a key: time, date, timers, math, jokes, "open YouTube", "search for ...", "play ...".

Phones stop web pages from listening once you leave the page or lock the screen. While Jarvis is active the screen stays on, so keep this page open (a dock or stand works well).

Use Chrome on Android. If the microphone is blocked when this file is opened from Downloads, host it over HTTPS (Netlify Drop or GitHub Pages), or in Termux run python -m http.server 8000 in the folder and open http://localhost:8000/jarvis-mobile.html.

Say "go to sleep" for standby or "shut down" to turn it off.
